# Level-Up Gamer - Frontend E-commerce

Este proyecto corresponde a la Evaluación Parcial N°1 de la asignatura Desarrollo FullStack II. Consiste en la maquetación y validación del frontend de una tienda web orientada a la cultura gamer, implementando un diseño responsivo y funcionalidades interactivas simuladas sin el uso de bases de datos.

## Características Principales

* **Estructura Semántica:** Código construido bajo los estándares de HTML5 utilizando etiquetas como `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
* **Diseño Responsivo:** Interfaz adaptada para dispositivos móviles, tablets y computadores de escritorio utilizando Bootstrap y CSS personalizado.
* **Estética Gamer:** Diseño visual enfocado en la cultura gamer, predominando el fondo oscuro (#000000) con acentos en verde neón y azul eléctrico.
* **Validación de Formularios:** Uso de JavaScript puro para validar en tiempo real los datos ingresados por el usuario, mostrando mensajes de error personalizados y controlando eventos.
* **Panel de Administración:** Vistas protegidas simuladas mediante `localStorage` para la gestión del inventario de productos y el control de usuarios del sistema.
* **Trabajo Colaborativo:** Desarrollo gestionado a través de Git y GitHub, con distribución de tareas equitativa y control de versiones.

## Tecnologías Utilizadas

* HTML5
* CSS3
* Bootstrap 5.3.3 
* Vanilla JavaScript
* Git y GitHub

## Estructura del Proyecto

La arquitectura del proyecto sigue las buenas prácticas de separación de responsabilidades, utilizando una base común para facilitar el mantenimiento:

* `/css/style.css`: Archivo único de estilos personalizados para toda la plataforma.
* `/js/funciones.js`: Archivo único centralizado con la lógica de validación de todos los formularios y manejo del DOM.
* `/img/`: Directorio destinado a los recursos gráficos del proyecto.
* `/*.html`: Vistas públicas (tienda) y privadas (administrador) ubicadas en la raíz del proyecto.

## Instalación y Uso

1. Clona este repositorio en tu máquina local.
2. No se requiere instalación de dependencias ni servidores locales.
3. Abre el archivo `index.html` en cualquier navegador web moderno para iniciar la navegación.
